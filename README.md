##Student Management System

The Student Management System will read a list of students off of a .txt file and it will list them in an array and give them an id number and list grade, name, age, etc. 

The project needs a .txt file in the same folder or you need to change the directory in the code. The .txt file looks like:

Lucian, 12
Trin, 15
Jonah, 64

So then the project using the String methods finds the Name and Age and then shows their Grade level and gives them a random ID.
